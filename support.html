Termina 1.0 · iPhone e iPad con iOS/iPadOS 17 o successivo

Scrivici: enricofanucchi@gmail.com. Rispondiamo di solito entro due giorni lavorativi.

Indica la versione dell'app (in fondo alle Impostazioni di Termina, ⌘,), modello del dispositivo, versione di iOS e, se puoi, il sistema del server (es. ssh -V). Non inviare mai password o chiavi private.

Primi passi

  1. Tocca + e inserisci indirizzo, porta e utente del server, oppure scrivi utente@host:porta in Connessione rapida.
  2. Scegli l'autenticazione: password, chiave importata o chiave generata nel Secure Enclave.
  3. Tocca il server: conferma l'impronta al primo collegamento e sei nella shell.

Domande frequenti

Come uso una chiave del Secure Enclave?

Nella scheda del server scegli Secure Enclave e tocca Genera chiave. Copia la riga che inizia con ecdsa-sha2-nistp256 e aggiungila a ~/.ssh/authorized_keys sul server. La chiave privata non lascia mai il chip del dispositivo, quindi è valida solo su quel dispositivo: su un altro iPhone o iPad ne genererai un'altra.

Quali chiavi posso importare?

Chiavi OpenSSH Ed25519 e RSA, anche protette da passphrase, che iniziano con -----BEGIN OPENSSH PRIVATE KEY-----. Se la tua chiave RSA è in un formato più vecchio, convertila sul computer con ssh-keygen -p -f ~/.ssh/id_rsa.

Vedo “la host key è cambiata”: cosa faccio?

Significa che il server si presenta con un'identità diversa da quella confermata in passato. Può succedere dopo una reinstallazione del server, ma può anche indicare un tentativo di intercettazione. Verifica l'impronta direttamente sul server (ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub). Se corrisponde, tieni premuto il server nell'elenco e scegli Dimentica host key, poi ricollegati.

La mia tastiera non ha il tasto Esc

Usa ⌘ . oppure il tasto esc della barra sopra la tastiera. In alternativa puoi trasformare Caps Lock in Esc: Impostazioni › Generali › Tastiera › Tastiera fisica › Tasti modificatori.

Come premo Ctrl su iPhone?

Tocca ctrl nella barra sopra la tastiera, poi il tasto desiderato: per esempio ctrl e poi c invia Ctrl-C. alt funziona allo stesso modo.

Perché la sessione si chiude quando cambio app?

iOS sospende le connessioni di rete delle app in background dopo circa 30 secondi. Termina si riconnette da sola quando torni. Per ritrovare la shell esattamente com'era, imposta una sessione tmux nella scheda del server (serve tmux installato sul server).

Il tunnel locale non risponde da Safari

I tunnel locali funzionano finché Termina resta in primo piano. Su iPad apri Safari e Termina affiancati (Split View o Slide Over), poi visita http://localhost:PORTA. Se il tunnel è in errore, controlla che sul server sia attivo AllowTcpForwarding.

Come raggiungo i miei server con Tailscale?

Installa e attiva l'app Tailscale, poi usa l'indirizzo 100.x.y.z o il nome *.ts.net del server. Termina indica nella barra laterale se Tailscale è attivo.

Come trasferisco e modifico i file?

Durante una sessione apri File (⇧ ⌘ F). Trascina i file dall'app File per caricarli, tocca un file per vederlo o modificarlo (testo fino a 2 MB). Il salvataggio sostituisce l'originale solo a caricamento completato, mantenendo i permessi.

Come elimino tutti i miei dati?

Eliminando un server ne cancelli anche le credenziali. Disinstallando l'app elimini tutto il resto: alla successiva installazione Termina cancella anche le eventuali voci rimaste nel Portachiavi. Non conserviamo copie da nessuna parte: vedi la Privacy.
